# Lecture01: Scientific Method & Reproducible Research

## Core Idea
- Science = writing things down
- No documentation = not science, just messing around

## Reproducibility Problems
- Authors can't reproduce own results
- Missing: data, code, documentation
- Reviewers can't verify claims
- Analysis not reproducible even with data

## Common Code Issues
- Version mismatch - can't find exact code
- No backups - data loss = failure
- "Code coming soon" - never released
- Team member leaves - knowledge lost
- Commercial code - can't share
- Time cost - maintaining vs research

## Solutions
- Version control: Git
- Document everything
- Share data
- Preprints: arXiv, HAL
- Release code with license
- Reproducibility declaration
- Verification + validation

## Field Problems
- Genomics: computational issues, big data
- Fluid dynamics: numerical precision
- Computer systems: complexity, randomness

## Computational Documents
- Combine: code + docs + results
- Tools: R Markdown, Jupyter, Org-mode
- Makes reproduction easier

## Data Management (FAIR)
- Findable
- Accessible
- Interoperable
- Reusable

## Takeaway
- Transparent methods
- Version everything
- Share data
- Clear documentation
